# OpenCode для iPhone

Отдельное приложение: свой интерфейс, свой бандл `dev.opencode2.mobile`.
Собирается на Linux, без Xcode и без сети.

## Что внутри

- Экрана два: главный и переписка. Между ними обычный push-переход.
- **Главный**: знак-искра, крупное приветствие с радужной второй строкой,
  полоса подсказок, список черновиков. Внизу поле ввода и честная
  подпись, что связи с сервером нет.
- **Переписка**: сообщения пузырями, время и пометка «Черновик».
  Долгое нажатие на сообщение копирует текст.
- **Настройки**: системная / светлая / тёмная тема, версия, бандл.
- Всё, что набирается, лежит в `NSUserDefaults` на телефоне.

Черновик удаляется долгим нажатием на строку в списке.

## Сборка

```bash
./build.sh
```

Нужны iPhoneOS SDK и `ldid`:

- SDK: `~/iosbuild/sdk/sdks-master/iPhoneOS16.5.sdk` (или `OC_IOS_SDK=...`)
- подпись: `~/iosbuild/ldid-bin` (или `LDID_BIN=...`)

На выходе `OpenCode-1.0.0.ipa`. Подпись ad-hoc, каталог `.app` целиком:
хэш `Info.plist` и все страницы кода на месте, entitlements отсутствуют.

## Установка

1. Открыть `.ipa` в iloader (или AltStore / Sideloadly).
2. Установщик переподпишет приложение своим сертификатом Apple ID.
3. Бандл совпадает с прошлым OpenCode, поэтому приложение встанет
   на его место. Если старую версию ставили другим сертификатом,
   сначала удалите её с телефона, иначе установка упрётся в подпись.

## Чего пока нет

Подключения к серверу OpenCode: ни запросов, ни ключей, ни адреса.
Сообщения не отправляются, ответов нет. Это заготовка интерфейса,
а не рабочий клиент.
